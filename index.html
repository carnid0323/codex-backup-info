Codex Development Backup

個人の開発ファイルを、自分のGoogle Driveへ暗号化してバックアップするための私用接続です。一般向けのアプリやバックアップサービスではありません。

用途とアクセス範囲

PC故障に備えて、利用者が選んだ開発ファイルを保管・復元する用途に限ります。Google Driveへの権限は drive.file に限定し、この接続で作成したバックアップファイルを扱います。既存のDrive全体やGmailへのアクセスは要求しません。

バックアップの内容、開発中のアプリ、接続情報、復元キーはこのサイトでは公開しません。この説明ページはバックアップの完了を保証するものではありません。

Google、GitHub、OpenAIが提供する製品ではなく、個人で管理する接続設定です。

プライバシー方針 / Privacy policy

English

This is a personal connection for backing up selected development files, encrypted locally, to the owner's Google Drive. It is not a public backup service. Only the Google Drive drive.file scope is requested. Project files, backup contents and credentials are not published on this website.
